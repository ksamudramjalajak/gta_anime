# GTA Anime Landing Page

A cinematic GTA-inspired anime landing page built with React, Vite, GSAP, Tailwind CSS, and Remix Icon.

## Features

- Animated VI-style intro mask
- GSAP-powered hero, character, text, and background motion
- Responsive desktop and mobile layouts
- Scroll-triggered story-section animations
- Layered Vice City artwork and anime character art
- Looping lofi background music with a mute/play control
- Smooth navigation between the hero and story sections

## Tech Stack

- React 19
- Vite
- GSAP and ScrollTrigger
- Tailwind CSS
- Remix Icon

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open `http://localhost:5173`.

### Build for production

```bash
npm run build
```

### Lint

```bash
npm run lint
```

## Project Structure

- `src/App.jsx` - Page structure and animations
- `src/index.css` - Global styles and responsive rules
- `public/` - Images, font, and background music
